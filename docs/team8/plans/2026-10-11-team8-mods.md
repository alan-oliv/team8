# team8 mods Implementation Plan

> **For agentic workers:** this plan is executed by teammates that `team8:run` dispatches from the shared task list. Read your own task section. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code mod in the team8 plugin wakes the lead when a teammate's completion unblocks a pending task whose owner is idle or not running, replacing the executor's "unblocks" message.

**Architecture:** A pure rule (`plugin/hooks/wave.ts`) decides which tasks to report and words the notice. The plugin's hooks module (`plugin/hooks/wave-notify.ts`) hooks `tool.call` on `TaskUpdate`, and 1 s after a teammate's completion reads the roster and `TaskList`, runs the rule and fires an unawaited `$.prompt.submit`. The executor's prose message goes; `team8:run` says what to do with a notice.

**Tech Stack:** Claude Code 2.1.296 function hooks (mods, early access), TypeScript, vitest.

**Spec:** `docs/team8/specs/2026-10-11-team8-mods-design.md`

## Global Constraints

- Mods are the default path: the notifier has no classic fallback, and the executor's `#N completed; unblocks #M` message is removed.
- The module ships as source in `plugin/hooks/`; Claude Code compiles it. `plugin/dist` is never committed.
- The hook never holds or changes a `TaskUpdate`: it returns `next(e)`'s result unchanged, and its registration has `.catch(($, e, next) => next(e))`.
- `$.prompt.submit` is never awaited.
- A function that takes `$` is a top-level function declaration (`claude plugin validate` refuses `$` passed to anything else).
- Notice text, verbatim shape: `team8: #<completed> completed. Unblocked with nobody on it: #<id> "<subject>" (owner <owner>, <why>). Dispatch per team8:run.`, entries joined with `; `, `<why>` being `idle` or `not running`.
- Busy roster statuses are `pending`, `running`, `waiting`; `idle` is idle; an absent owner, or one `completed`, `failed` or `killed`, is not running. Owners match roster entries by `name`.
- Commit by pathspec (`git commit -- <paths>`). No AI attribution or "generated with" footer in any commit.

Create `plugin/hooks/wave.ts`:

```ts
// The wave notifier's rule, kept free of Claude Code imports so vitest and
// the repo's typecheck can load it; wave-notify.ts is the module around it.

export type ListedTask = { id: string; subject: string; status: string; owner?: string; blockedBy: readonly string[] };
export type RosterEntry = { name?: string; status: string };
export type Unblocked = { id: string; subject: string; owner: string; why: 'idle' | 'not running' };

const BUSY = new Set(['pending', 'running', 'waiting']);

// TaskList's blockedBy holds only open blockers, so an empty one means unblocked.
// A respawn leaves the old agent in the roster under the same name, so every
// holder of the name counts.
export function unblockedIdle(
  tasks: readonly ListedTask[],
  roster: readonly RosterEntry[],
  notified: ReadonlySet<string>,
): Unblocked[] {
  const found: Unblocked[] = [];
  for (const t of tasks) {
    if (t.status !== 'pending' || t.blockedBy.length > 0 || !t.owner || t.owner === 'team-lead') continue;
    if (notified.has(t.id)) continue;
    const statuses = roster.filter((a) => a.name === t.owner).map((a) => a.status);
    if (statuses.some((s) => BUSY.has(s))) continue;
    found.push({ id: t.id, subject: t.subject, owner: t.owner, why: statuses.includes('idle') ? 'idle' : 'not running' });
  }
  return found;
}

export function noticeText(completedId: string, unblocked: readonly Unblocked[]): string {
  const items = unblocked.map((u) => `#${u.id} "${u.subject}" (owner ${u.owner}, ${u.why})`).join('; ');
  return `team8: #${completedId} completed. Unblocked with nobody on it: ${items}. Dispatch per team8:run.`;
}
```

Create `plugin/hooks/wave-notify.ts`:

```ts
import type { EngineInterface, Register } from 'claude-code'
import { noticeText, unblockedIdle } from './wave.ts'

// ponytail: the reported ids live in module memory, so a reload can repeat a
// notice; move them to $.state if that turns into noise.
const notified = new Set<string>()

async function notify($: EngineInterface, agentId: string, completedId: string) {
  try {
    const roster = await $.agent.list()
    if (!roster.some(a => a.id === agentId && a.teammateId)) return
    const list = await $.tool.call({ tool: 'TaskList' })
    const unblocked = unblockedIdle(list.result?.tasks ?? [], roster, notified)
    if (unblocked.length === 0) return
    for (const u of unblocked) notified.add(u.id)
    void $.prompt.submit({ text: noticeText(completedId, unblocked) })
  } catch {
    // A failed read costs only this notice.
  }
}

export const register: Register = on => {
  on('tool.call', { tool: 'TaskUpdate' }, async ($, e, next) => {
    const r = await next(e)
    const change = (r.result as { statusChange?: { to: string } } | undefined)?.statusChange
    if (e.agentId && change?.to === 'completed') {
      const { agentId, taskId } = e
      // A timer, so the teammate's call returns without waiting on the roster
      // and TaskList reads, which then run outside its loop.
      $.clock.after(1000, () => void notify($, agentId, taskId))
    }
    return r
  }).catch(($, e, next) => next(e))
}
```
